# 香港中转服务器（大陆加速）

2026-11-10 站长批准。目的：大陆客户打开网站/接口/链上数据走「大陆 → 香港 → 源站」，延迟几十毫秒；网站代码、合约、数据一行不动。

## 架构
- 香港轻量服务器跑 nginx：
  - `/rpc` → rpc.anubispace.org（链上节点中转，带 CORS）
  - `/api/` → ailgns.dev（Cloudflare 后端；GET 缓存 5 秒、后端出错先给旧数据；POST 直通）
  - `/` → ailgns.dev（网页和静态文件香港本地缓存）
  - `/hk/ping.txt` → 直接返回 ok（发布页测速用）
- 备用域名 ailgnsotc.cc 的 DNS 改成「仅 DNS」直指香港 IP（不走 Cloudflare）。
- App 发布页实测各网址延迟、自动排最快的在最上；页面 RPC 列表在 ailgnsotc.cc 上优先 `/rpc`。
- 一键脚本：`hk/setup.sh`（线上地址 https://ailgns.dev/hk/setup.sh），里面带技术团队 Mac 的 SSH 公钥，跑完后可远程维护。

## 站长买服务器的步骤（2026-11-10 改：不用大陆公司，大陆最快优先 → DMIT 香港）
DMIT：美国公司（洛杉矶），香港机房 CN2 GIA 三网直连，大陆延迟 30–50 ms，约 US$37/月，支持支付宝 / PayPal / 信用卡。备选：搬瓦工香港 CN2 GIA（更贵常缺货）、Azure 香港（流量按 GB 收费）、Oracle 东京/首尔免费机（当第二条线路）。Vultr 没有香港机房、IP 常被封，不作首选。
1. 打开 dmit.io → 右上角 Register，邮箱注册。
2. 顶部 Store → **Hong Kong** → **PVM.HKG.Pro** 系列，选最小一档（1 核 2G、1TB 流量）。
3. Operating System 选 **Ubuntu 24.04**；Billing Cycle 选 Monthly，先买 1 个月。
4. 付款（Alipay / PayPal / 信用卡）。
5. Client Area → Services → 点进机器：记下 **IP** 和 **root 密码**，密码存 1Password「AiLGNS · 香港中转服务器」。
6. 机器页面点 **VNC / Console** 网页终端，用户名 root 登录，粘贴：
    ```
    curl -fsSL https://ailgns.dev/hk/setup.sh | sudo bash
    ```
7. 显示「✅ 配置完成」后把 IP 发到会话里。DMIT 防火墙默认全开，不用设。

## 之后我做的（不用站长动手，除了 DNS 那一步要点几下）
- SSH 进去检查，装 HTTPS 证书（需要先把 ailgnsotc.cc 指过来）。
- Cloudflare DNS：ailgnsotc.cc 的 A 记录改成香港 IP，云朵关掉（仅 DNS）。我一步步说点哪里。
- 发布页测速选网址、RPC 列表加香港中转，先推 preview 看，再上 main。
- Cloudflare 的客服限流规则（/api/chat 每 IP 8 次/10 秒）会把香港 IP 当成一个人：要放宽或按 X-HK-Proxy 头排除，否则大陆客户共用一个 IP 会被限。
- 以后巡检加一条：香港机器健康（/hk/ping.txt 和 /rpc 的 eth_blockNumber）。
