# 游戏自动开发 · 规则（站长 2026-11-25 定：游戏板块免审、全自动）

站长原话：「免审，全自动板块，游戏放权，x 上什么火，开发什么」。「农场我们自己在维护」。
这份规则给每天自动跑的云端 AI 看。**规则和任务提示冲突时，以更保守的为准。**

## 目标
一次只养一个新游戏，做深，做到有人天天回来玩；数据不行就下架换下一个。不是批量出小游戏（2026-11-23 已经因为没人玩下架过 9 个）。

## 每一轮（每天一次）按顺序做
1. **读状态**：`docs/游戏自动开发/状态.md`（现在养的是哪个游戏、哪天上线、昨天改了什么、数据）。
2. **看数据**：`https://ailgns.dev/api/games-top`（最近 7 天每个游戏打开次数）+ 这个游戏自己接口里的统计（玩了几局、多少人第二天回来）。
3. **定今天做什么（产品 AI）**，三选一：
   - 现在没有在养的游戏 → 调研选题（见下），立项一个新游戏，做出能玩的第一版。
   - 有在养的游戏、数据在涨或上线不满 14 天 → 只做**一个**小改动（修最影响体验的问题 / 加一个让人明天还想来的东西）。
   - 上线满 14 天、最近 7 天打开不到 300 次 → 从菜单撤下入口（文件留着），在状态里写明原因，下一轮重新选题。
4. **开发（开发 AI）**：只动白名单里的文件。写完 `node --check`，规则引擎要写能直接跑的自测。
5. **检查（检查 AI，用子助手、不带开发时的结论）**：重读一遍改动，对照这份规则逐条核；跑 `python3 tools/games_guard.py`，不过就不许推。
6. **上线**：`python3 tools/build.py` → 提交 → 推 `main`。推完等自动体检（`.github/workflows/after-deploy.yml`，约 13 分钟）；如果 main 上出现「自动退回」提交，今天不再重试，把原因写进状态。
7. **写报告**：更新 `状态.md`，在 `docs/游戏自动开发/日志/` 写当天一份短报告（做了什么、数据、明天打算）。

## 选题（「X 上什么火，开发什么」）
- 用网页搜索看 X（推特）和游戏媒体上最近在火的**玩法类型**。
- **只借鉴玩法类型和机制，必须原创**：不许照搬某个现成游戏的名字、角色、美术、音乐、关卡、界面长相；改个名字也不行。
- 优先选符合这几条的：手机竖屏单手能玩；一局 1～3 分钟；每天有理由回来（每日挑战 / 排行榜 / 体力恢复 / 连续签到）；能和朋友比。
- 不选：赌博、抽奖、押注、涉及真钱的玩法；血腥、色情、政治内容。

## 红线（碰了就算事故）
- **不碰钱**：新游戏是纯娱乐。不收费、不充值、不提现、不转赠、不上链、不发任何币或奖励；不用农场金币（农场站长自己维护）；不连钱包发交易、不签名、不授权。只允许**读**当前钱包地址和域名用来显示昵称。
- **不碰别的板块**：OTC、借贷、域名、预言家、看盘、账本、农场、掼蛋、麻将、大逃杀、合约、机器人、GitHub 流程，一行都不改。
- **不加新地址**：代码里不出现任何 `0x` 开头的合约 / 钱包地址。
- **不做营销**：不群发通知、不改首页、不弹窗拉人。只在「☰ 更多」的游戏那一组加入口。
- **对外口径**：永远说「团队 / 技术人员」。

## 文件白名单（`tools/games_guard.py` 会强制检查）
- 随便改（新游戏自己的文件）：`gx-*.js`、`functions/api/gx-*.js`、`lib/gx-*.js`、`icons/gx/**`、`i18n/en/9*-gx-*.json`、`docs/游戏自动开发/**`
- 构建产物：`dist/**`、`index.html`
- 只许小幅追加的接线文件（把新游戏挂进网站）：`app.js`、`menu.js`、`tools/build.py`、`index.src.html`、`style.css`、`tools/healthcheck.mjs`、`lib/updates.js`、`chat.js`、`lib/chatbot.js`、`i18n/ko/02-extra.json`、`night.js`
- 其它任何文件都不许动。

## 写代码的规矩
- 新游戏的页面路由、文件名、样式前缀都用 `gx` 开头加游戏英文名（先 `grep` 全站确认没人用过这个前缀）。
- 数据只存自己的 KV 键：`gx:<游戏名>:…`。接口里每个写操作都要限频、限大小。
- 先适配手机 390 宽。新 UI 用网站自己的浅紫配色。不用系统弹窗（`alert/confirm/prompt`）。
- 全站脚本必须 `try/catch`，游戏出错不能让整站白屏。
- 文案用大白话；新增中文文案要补英文（`i18n/en/9x-gx-<名>.json`）和韩文（`i18n/ko/02-extra.json`）。
- 上线时同步客服知识（`chat.js` 的常见问答 + `lib/chatbot.js` 的 KNOWLEDGE）和更新日志（`lib/updates.js`），只写公开信息。
- 素材版本号 `?v=` 不许复用旧的。
- 提交说明结尾加一行：`Co-Authored-By: Claude <noreply@anthropic.com>`

## 什么时候通知站长（只在这几种情况，用 `/api/notify-owner`）
- 新游戏第一次上线；游戏被下架；被自动退回；某个游戏最近 7 天打开超过 2,000 次（起量了）。
- 平时不发消息，报告只写进仓库。

## 每天花费
一轮只做一件事。拿不准、做不完、检查没过：**今天就不上线**，写进状态，明天接着做。宁可空一天，不要带病上线。
