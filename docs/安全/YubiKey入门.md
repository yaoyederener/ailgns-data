# YubiKey 5C NFC 入门（站长自学笔记，2026-11-08）

## 它到底是什么
一把「硬件钥匙」。插电脑的 USB-C 口，或者贴一下手机背面（NFC）。登录账号时，网站除了密码，还要求你**碰一下这把钥匙**才放行。
原理：钥匙里有一个永远读不出来的私钥，网站发一道题，钥匙用私钥签名答题。密码可以被盗、被钓鱼，这把钥匙的私钥**拿不出来、复制不了**，不碰钥匙就登不上。

## 安全程度（大白话）
- 防钓鱼：假网站骗不了它。钥匙签名时会带上真实网址，在假网址上签出来的东西真网站不认。这是它比「短信验证码 / 谷歌验证器」强最多的地方。
- 防远程盗号：黑客拿到你密码也没用，钥匙在你口袋里。
- 防不了：你本人被骗着亲手操作、电脑已经被装了木马（木马可以等你登录后劫持会话）、钥匙本身被偷走（所以要配 PIN）。
- 结论：对你这种「钱包 + 交易所 + Google + GitHub + Cloudflare 全在一个账号体系里」的人，这是性价比最高的一道防线。

## 为什么买三把是对的
- 一把日常用（钥匙扣上）。
- 一把备份（家里抽屉或保险柜）。
- 一把异地备份（父母家 / 办公室）。
每个账号都要**把三把全部注册上去**，丢了一把立刻用另一把登录、把丢的那把删掉。只注册一把 = 钥匙丢了账号就进不去。

## 先绑哪些账号（按风险从高到低）
1. **Google 账号**（谷歌社交账号钱包用它登录，所有收入在这）：Google 账号 → 安全性 → 两步验证 → 安全密钥 → 添加，三把各加一次。加完建议开「高级保护计划」：开了以后只认硬件钥匙，彻底不认短信和验证器。
2. **GitHub**（两个仓库 + 所有机器人密钥都在 secrets 里）：Settings → Password and authentication → Security keys → 添加三把。
3. **Cloudflare**（网站本身）：My Profile → Authentication → Security Keys。
4. **1Password**（所有私钥存这里）：1Password.com → 个人资料 → 两步验证 → Security Key。
5. **交易所 / 邮箱 / Telegram** 等：支持「安全密钥 / FIDO2 / WebAuthn / Passkey」的都绑上。
绑完每个账号，把它原来的短信验证**关掉**，否则黑客还能走短信那条路。

## 怎么用（日常）
- 电脑：登录时网页弹「请插入安全密钥」，插上，钥匙亮灯，**用手指碰一下金属圈**（不是指纹，只是确认有真人在）。
- 手机：弹提示后把钥匙**贴到手机背面上方**（iPhone 贴顶部摄像头附近），等震动。
- 设 PIN：第一次用时会让设一个 FIDO2 PIN（4–8 位），钥匙被偷也用不了。三把设同一个，记在 1Password 里。
- 还能当 Passkey（通行密钥）用：以后很多网站可以「不要密码，只碰钥匙」。

## 注意
- 别用它存加密货币私钥，它不是硬件钱包（那是 Ledger / Trezor 的活）。
- 丢了一把：立刻用另一把登录每个账号，删掉丢的那把。
- 别把三把放一起。
- 每半年拿备份钥匙登录一次，确认它还好使。
