# 链上广场（去中心化论坛 / 聊天）思路稿

2026-11-07 深夜 · 站长要求：写思路，后期一起优化。原则：放在「链上身份」菜单里，不宣传，客户自己发现自己玩；只更新客服知识库；不指望收费，要好玩、要酷。

---

## 一、别人做过什么，成了的和死了的

| 项目 | 玩法 | 结果 | 给我们的教训 |
|---|---|---|---|
| Farcaster / Warpcast | 链上身份 + 频道 + 「Frames」（帖子里直接按按钮做链上操作：投票、铸造、买东西） | 活下来了，几十万真实用户 | 身份要稀缺、帖子要能「做事」不只是说话。Frames 是它爆的原因 |
| Friend.tech | 买卖「别人的钥匙」才能进他的聊天室 | 三个月火到顶，然后归零 | 靠投机拉来的人，投机一停就走。我们不做这种 |
| Steemit | 发帖赚币 | 刷子横行，内容垃圾化 | 发帖不能给钱，给钱就全是刷子 |
| Nostr | 任何人跑节点，账号就是一对密钥 | 小众但死不掉 | 「删不掉、封不掉」本身就是卖点，但没有身份成本就全是垃圾 |
| 早期贴吧 / 天涯 | 按话题分吧，长帖、盖楼 | 火了十年 | 中国人喜欢「盖楼」和「围观」，不喜欢碎片流 |
| 比特币创世区块那句话 | 一句话永久刻在链上 | 被引用了十五年 | 「永久」本身就是浪漫，人愿意为「留一句话给未来」付钱 |

结论：成的都有两样东西，**稀缺的身份** 和 **帖子能做事**。死的都是靠发钱或投机拉人。

## 二、我们手里有什么别人没有的

1. **身份要花钱买**：.ailgns 名字 5 DAI 起，永久，一个钱包一个主名。骗子和刷子换一次身份就要再花钱、再从零开始。
2. **说话要花 Gas**：一条 0.001 DAI，不贵，但足够让人「想清楚再说」。没人能群发。
3. **删不掉**：包括我们自己也删不掉。承诺、告白、预测、证据，都适合刻在这里。
4. **账本已经有了**：每个名字点开就是他的全部链上行为（成交、挂单、留言、预测）。信誉不用建，天然就有。
5. **预言家已经有了**：每天一个全站共同话题（今晚揭晓价），这是论坛最难得的「每日仪式」。

## 三、怎么才能火：五个「好玩」

### 1. 一句话刻一辈子（时间胶囊 / 告白墙 / 立字据）
- 任何人可以给「未来」留言：选一个日期，到期前全站不显示，到期那天公开。
- 给某个名字留「立字据」：「我欠 xxx 100 DAI，11-30 前还」，双方名字都在链上，永久。
- 这是第一个让人「忍不住截图发朋友圈」的功能，而且零成本：就是留言加一个日期字段。

### 2. 帖子能做事（学 Frames）
- 帖子下面不是只有「回复」，还有按钮：「按这个价买」「我也预测」「打赏 1 DAI」「投票」。
- 卖家发一帖「我有 10 个 AiLGNS，830 出」，买家在帖子里点一下就成交，聊天记录就是合同。
- 这把论坛和 OTC 主业焊在一起：论坛有内容，OTC 有成交。

### 3. 每日一题（和预言家绑定）
- 每天 21 点揭晓价公布后，自动生成当天的帖子「今天 832.205，你猜了多少？」，所有人的预测自动挂在下面，猜中的名字高亮。
- 不用运营，天天有话题，天天有人围观。

### 4. 盖楼与围观（贴吧式）
- 不做无限下拉的信息流，做「帖子 + 楼层」。楼层按链上顺序编号，「抢沙发」「第 100 楼」自带仪式感。
- 热帖榜 = 回帖数 × 不同名字数，刷不了（每层楼都要花 Gas，还要不同的名字）。

### 5. 名字即勋章
- 创世编号、注册时长、成交次数、预言家中奖、被举报次数，全部自动显示在名字旁边。
- 老名字说话自带分量，新名字老老实实。信誉是算出来的，不是打出来的。

## 四、站长拍板（2026-11-07 深夜）：按全球最火的玩法做 = Farcaster 路线

一句话：**身份（名字）+ 频道（板块）+ 帖子能做事（Frames）**。顺序随之调整：帖子按钮提前到 V2，它是火的核心，不往后拖。

## 四、分几步做（每步只碰一小块，不碰合约）

| 步 | 做什么 | 改哪里 | 碰钱吗 |
|---|---|---|---|
| V1 | 留言升级：可以回复某条留言（带上父交易哈希），形成楼层；「链上身份」菜单里加「🏛️ 链上广场」入口，先只有一个板块「广场」 | msg.js + scan.js + 新页面 | 否 |
| V2 | 帖子按钮（Frames）：卖家发帖自带「按这个价买」，点一下走现有 OTC 吃单；「打赏 1 DAI」；「我也预测」跳预言家 | 复用 OTC 吃单和转账 | 是，先 preview，你小额走一遍 |
| V3 | 每日一题：预言家揭晓后自动发帖、预测自动挂楼 | oracle keeper + 页面 | 否 |
| V4 | 时间胶囊 / 立字据：留言加「公开日期」字段 | msg.js + 页面 | 否 |
| V5 | 板块 + 热帖榜 + 举报黑名单 + 名字勋章 | 页面 + KV | 否 |
| V6 | 加密私信（公钥加密，上链但只有对方能看） | 纯前端 | 否 |

每步都走：preview → 你审 → 推送上线 → 只更新客服知识库，不发公告。

## 五、底线（和之前定的规矩一致）

- 发帖必须有 .ailgns 主名字；网址、联系方式一律拦；政治词一律拦。
- 不给发帖奖励，不发币，不搞积分。好玩靠玩法，不靠发钱。
- 不宣传、不推送、不弹窗。客户自己在「链上身份」里发现。
- 删不掉，但本站可以不显示：举报满 3 个不同名字自动隐藏，你在后台一键拉黑。
- 不碰 OTC / 借贷 / 域名合约。所有东西都是 0 元交易 + 网站索引。
