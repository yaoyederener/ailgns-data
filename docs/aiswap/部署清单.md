# aiswap 第一阶段 · 部署清单（站长照着点）

> 2026-11-09 整理。目标：在 Anubis 链上，用**站长自己的钱包**，把 PancakeSwap V2 的三个合约**一行不改**地部署一遍，手续费从第一天就开。
> 私钥永远只在你的钱包 App / 硬件钱包里：**不进聊天、不进代码、不进任何网页的输入框**。下面所有步骤都是「钱包弹窗 → 你点确认」。

## 0. 先搞懂三件事（3 分钟）

**要部署什么**（都是现成的、别人审计过、用了好几年的代码）：

| 合约 | 干什么 | 谁能管 |
|---|---|---|
| WETH9 | 把链上的 Gas 币（gasDAI）包成普通代币。Router 构造时必须填一个，先放着备用 | 没有管理员 |
| PancakeFactory | 「开池子」的工厂：任何人给两个币就能开一个池子 | 只有 `feeToSetter`（= 你的钱包）能改「平台费收到哪」 |
| PancakeRouter | 客户点「兑换 / 加流动性 / 撤流动性」时真正调用的合约 | 没有管理员，部署完谁都改不了 |

**费率**（写死在 PancakePair 代码里，部署后改不了）：每笔兑换收 **0.25%**，其中 **0.17% 留在池子里归所有 LP，0.08% 归平台**（收款地址 = 谷歌社交账号钱包 `0xedb9c6900a11d2dd37da6b59f3604c35a39db1e6`）。
注意：平台这 0.08% **不是直接到账 DAI**，而是以「池子份额（LP 凭证）」的形式攒在收款钱包里，每次有人加 / 撤流动性时结算一次。想变现就拿这些份额去撤流动性，换回两种币。

**Anubis 链参数**（2026-11-09 直接从节点读出来核对过）：

| 项目 | 值 |
|---|---|
| Chain ID | 6714（十六进制 0x1a3a） |
| RPC | https://rpc.anubispace.org （备用 rpc2 / rpc3.anubispace.org） |
| Gas 币 | gasDAI（钱包里显示 DAI，18 位小数）。Gas 价约 12 gwei，没有 EIP-1559 基础费（baseFee = 0） |
| 区块 Gas 上限 | 1 亿（部署再大的合约都放得下） |
| 官方浏览器 | https://browser.anubispace.org （Blockscout 风格，支持开源验证） |
| 本站账本 | https://ailgns.dev/#/scan/交易哈希 |
| ERC20 DAI | `0x83fd06F0846d9D90B3016bF670Efe2E0B11cDe14`（"Dai Stablecoin"，**普通 ERC20，不是包装 Gas 币**：没有 deposit/withdraw 函数。现有所有池子用的都是它） |
| AiLGNS | `0x256EdB652db43E721EC6A12B6b51b6967D3bb8cB`（18 位小数） |
| 链上已有的第三方 DEX 工厂 | `0xaf6f4e641c86a25518509bc840051a8652af598a`（Uniswap V2 风格，914 个池子；只作参考，我们不碰） |

> **为什么还要部署 WETH9**：链上没有现成的「包装 gasDAI」合约（ERC20 DAI 和 Gas 币是两样东西，上面核对过）。Router 的构造函数必须填一个 WETH 地址，所以把 WETH9 原版部署一份。第一阶段前端只做 ERC20 ↔ ERC20（DAI、AiLGNS、新币），WETH9 只是让 Router 能部署，以后想让客户直接用 Gas 币买再打开。

## 1. 源码从哪拿（这一步最重要，决定「一行不改」有没有意义）

**现状（2026-11-09 核实）**：PancakeSwap 官方的 core 仓库（`pancakeswap/pancake-swap-core`、后来并入的 `pancakeswap/pancake-smart-contracts`）在 GitHub 上已经 **404**，官方开发文档 developer.pancakeswap.finance/contracts/v2/github 还链着它，但点进去是空的。GitHub 上只剩 `pancakeswap/pancake-swap-periphery`（master 最新提交 `d769a6d136b74fde82502ec2f9334acc1afc0732`，2020-09-23），而且它里面 `PancakeLibrary.sol` 写死的 init code hash 是 `d0d4c4cd…`（**V1 时代的**，和 V2 的 Pair 对不上），**不能直接用**。

所以**唯一权威、字节码可核对的源码 = BscScan 上开源验证过的 BSC 主网合约**（验证 = 链上字节码和这份源码编译结果一致，全世界几千亿美元成交量跑的就是这份）：

| 合约 | BSC 主网地址（去 bscscan.com 搜） | 编译设置（Sourcify 完全匹配核实） |
|---|---|---|
| PancakeFactory（内含 PancakePair、PancakeERC20） | `0xcA143Ce32Fe78f1f7019d7d551a6402fC5350c73` | Solidity **v0.5.16**（commit 9c3226ce），Optimizer **关**（runs 200），EVM istanbul |
| PancakeRouter（V2 Router02，内含 PancakeLibrary、TransferHelper、SafeMath） | `0x10ED43C718714eb63d5aA57B78B54704E256024E` | Solidity **v0.6.6**，Optimizer **开**，runs **999999**，EVM istanbul |
| WETH9 | 以太坊主网 `0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2` | Solidity **v0.4.19**（commit c4cbbb05），Optimizer **关**，EVM 默认。代码只有 60 行，肉眼能读完 |

**已经替你拿好了**：三份源码在本仓库 `docs/aiswap/contracts/`（PancakeFactory.sol、PancakeRouter.sol、WETH9.sol），2026-11-09 从 Sourcify 开源验证库下载，三份都是「创建码 + 运行码完全匹配」，编译参数见同目录 README.md。**参数照抄，一个数字都别改**：
- PancakeFactory.sol：solc 0.5.16，**optimizer 关**（runs 200），EVM istanbul
- PancakeRouter.sol：solc 0.6.6，**optimizer 开，runs 999999**，EVM istanbul
- WETH9.sol：solc 0.4.19，optimizer 关，EVM 默认

**核对「一行不改」的四个关键点**（复制下来后用编辑器搜索）：

| 搜什么 | 应该看到 | 意思 |
|---|---|---|
| `mul(25)` | PancakePair.swap 里 `balance0.mul(10000).sub(amount0In.mul(25))` | 总费 0.25% |
| `mul(8)` 和 `mul(17)` | PancakePair._mintFee 里 `…mul(8)` / `rootK.mul(17).add(rootKLast.mul(8))` | 平台拿 8/25 = 0.08%，LP 拿 0.17% |
| `9975` | PancakeLibrary.getAmountOut / getAmountIn 里 `amountIn.mul(9975)` | 报价按 0.25% 算 |
| `hex'00fb7f630766e6a796048ea87d01acd3068e8ff67d078148a3fa3f4a84f69bd5'` | PancakeLibrary.pairFor | Router 写死的 Pair 字节码指纹（第 4 步要和你部署的工厂核对） |

> 备注给以后：Uniswap V2 的源码仍在 GitHub（`Uniswap/v2-core` tag v1.0.1、`Uniswap/v2-periphery`），但协议费只有 0.05%（而且默认关着，1/6 份额）。你 11-11 定的是 Pancake 的 0.25% / 0.08%，这份清单按 Pancake 写。

## 2. 工具二选一

### 方案 A：Remix（推荐站长用，浏览器里点，钱包签名）

**最省事：点下面三条链接，Remix 会自动把源码装进去、把编译器版本和 optimizer 设好**（源码来自本仓库 preview 分支的 `docs/aiswap/contracts/`；合到 main 后把链接里的 `preview` 换成 `main` 也一样）。打开后仍然对一眼右侧「Solidity compiler」面板：版本、Enable optimization 勾没勾、runs、EVM，和下表一致再点 Compile。

| 合约 | 一键链接 |
|---|---|
| WETH9 | https://remix.ethereum.org/#version=soljson-v0.4.19+commit.c4cbbb05.js&optimize=false&runs=200&url=https://raw.githubusercontent.com/yaoyederener/ailgns-data/preview/docs/aiswap/contracts/WETH9.sol |
| PancakeFactory | https://remix.ethereum.org/#version=soljson-v0.5.16+commit.9c3226ce.js&optimize=false&runs=200&evmVersion=istanbul&url=https://raw.githubusercontent.com/yaoyederener/ailgns-data/preview/docs/aiswap/contracts/PancakeFactory.sol |
| PancakeRouter | https://remix.ethereum.org/#version=soljson-v0.6.6+commit.6c089d02.js&optimize=true&runs=999999&evmVersion=istanbul&url=https://raw.githubusercontent.com/yaoyederener/ailgns-data/preview/docs/aiswap/contracts/PancakeRouter.sol |

第一次打开 Remix 会弹「Cloud Workspaces」之类的欢迎窗，右上角 ✕ 关掉即可，不用登录。链接打开后文件在左侧文件树 `raw.githubusercontent.com/…/contracts/` 文件夹里，点一下文件名就在编辑器里打开了。

手动方式（链接打不开时）：

1. 浏览器打开 https://remix.ethereum.org （只用这个域名，别点搜索广告）。
2. 左侧「File explorer」→ 新建文件夹 `aiswap`，里面新建三个文件：`WETH9.sol`、`PancakeFactory.sol`、`PancakeRouter.sol`，把 `docs/aiswap/contracts/` 里三份源码**原样整份粘贴**（每份都是合并好的单文件）。
3. 左侧「Solidity compiler」：
   - 编译 `WETH9.sol`：Compiler **0.4.19**；Advanced Configurations 里 **不勾** Enable optimization。
   - 编译 `PancakeFactory.sol`：Compiler **0.5.16**；展开 Advanced Configurations → **不勾** Enable optimization（这一条最容易错，勾了 hash 就对不上）；EVM Version 选 **istanbul**。
   - 编译 `PancakeRouter.sol`：Compiler **0.6.6**；同样 ✅ optimization **999999**、EVM **istanbul**。
   - 每个文件编译完，底下「Compilation Details」能看到 `bytecode`。想和 BscScan 核对：BscScan 页面「Contract」→ 往下翻「Contract Creation Code」，和 Remix 的 `object` 比对，**除了末尾几十个字节（元数据指纹）外应完全一致**。第 4 步的 hash 核对是更直接的证明。
4. 左侧「Deploy & run transactions」：Environment 选 **Injected Provider**（MetaMask / OKX 等，钱包先切到 Anubis 链，Chain ID 6714）。确认上面显示的 Account 就是你要当「工厂管理员」的钱包。

## 3. 先彩排、再真上（「先测试网后主网」）

Anubis 没有公开测试网（2026-11-09 没查到任何测试网 RPC / Chain ID），所以用两步代替：

**3a. 本地彩排（零成本、和主网一模一样）**：装 Foundry 后一条命令起一个「Anubis 的本地分身」：

```bash
anvil --fork-url https://rpc.anubispace.org --chain-id 6714
```

钱包里加一个网络：RPC `http://127.0.0.1:8545`、Chain ID 6714。然后把下面第 4 步从头到尾点一遍（钱包用它自带的测试账户或你自己的地址，anvil 给的是假钱）。目的：熟悉每个弹窗、确认 hash 对得上、确认 setFeeTo 不会点错。关掉 anvil 什么都不留。
不想装 Foundry，就用 BSC 测试网（Chain ID 97，水龙头领 tBNB）照第 4 步部署一遍，一样零成本。

**3b. 主网小额**：第 4 步在主网走一遍，第 5 步只放 **10 DAI + 对应的 AiLGNS** 开第一个池子、兑换 1 DAI、再撤掉，看账本一切正常，再放真实流动性。

## 4. 部署顺序（主网，4 笔部署 + 1 笔设置，每笔 Gas 不到 0.1 DAI）

部署前：钱包切到 Anubis，里面留 **≥ 2 DAI**（Gas 币）。每一步成功后**把地址抄到下面的表格里**。

| # | 做什么 | Remix 里怎么点 | 抄地址 |
|---|---|---|---|
| ① | 部署 **WETH9** | Contract 选 `WETH9` → 橙色「Deploy」→ 钱包确认 | WETH = `0x________` |
| ② | 部署 **PancakeFactory** | Contract 选 `PancakeFactory` → Deploy 旁边输入框填 `_feeToSetter` = **你的钱包地址**（就是现在连着的这个，以后只有它能改平台费收款地址）→ Deploy → 确认 | FACTORY = `0x________` |
| ③ | 部署 **PancakeRouter** | Contract 选 `PancakeRouter` → 展开 Deploy 填两个参数：`_factory` = ② 的地址，`_WETH` = ① 的地址 → Deploy → 确认 | ROUTER = `0x________` |
| ④ | **核对 hash（最常见的坑）** | 在 Remix「Deployed Contracts」展开 Factory → 点蓝色 `INIT_CODE_PAIR_HASH` → 返回值必须是 **`0x00fb7f630766e6a796048ea87d01acd3068e8ff67d078148a3fa3f4a84f69bd5`**，和第 1 步源码里 `pairFor` 写死的那串一样 | ✅ / ❌ |
| ⑤ | **打开平台费** | 展开 Factory → `setFeeTo` 填 `0xedb9c6900a11d2dd37da6b59f3604c35a39db1e6` → 橙色按钮 → 钱包确认。然后点蓝色 `feeTo` 读一下，应显示这个地址 | ✅ |

**④ 不一致怎么办**：说明你编译出来的 PancakePair 字节码和 BSC 的不一样 —— 九成是编译器版本 / optimizer runs / EVM 版本填错了，回第 2 步改成完全一致再重新部署 ②③（不一致的话 Router 找池子会找错地址，兑换全部失败，钱不会丢但功能全废）。**不要**去改 Router 里那串 hash 来迁就 —— 那就不是「一行不改」了。

**用 Factory 开第一个池子不用单独操作**：第 5 步通过 Router 加流动性时，池子不存在会自动创建。

## 5. 主网小额验收（花 10 DAI 左右）

先把 ①②③ 的地址填进代码 `lib/aiswap.js` 的 `contracts` 里，开发推 preview，页面就从「测试网部署中」变成真功能。然后用一个**小钱包**（不是收款钱包）：

1. 打开 preview 站 `#/aiswap` → 「流动性」→ 选 AiLGNS / DAI → 填 10 DAI 和按市价对应的 AiLGNS → 授权两次（只需一次性）→「加流动性」→ 钱包确认。
2. 「兑换」→ DAI → AiLGNS，填 1 DAI → 看报价、看「最少到手」→ 确认。
3. 「池子」里应出现 AiLGNS / DAI，储备和 24h 成交有数。
4. 「流动性」→ 我的份额 → 「全部撤出」→ 两种币回到钱包（少了 0.25% 里属于 LP 的那部分会多回来一点）。
5. 每一笔都在本站账本看：`https://ailgns.dev/#/scan/<交易哈希>`（Remix / 钱包里都能复制哈希）。官方浏览器 `browser.anubispace.org/tx/<哈希>` 也能看。

全部正常 → 你说「推送上线」→ 开发合到 main。

## 6. 部署后两件收尾（不急，但要做）

1. **开源验证**：在 https://browser.anubispace.org 找到 ②③ 地址 → 「Verify & Publish」→ 粘同一份源码、同一套编译设置。验证通过后任何人都能在浏览器里看到和 BSC 一模一样的代码，这是对外最硬的「没有后门」证明。
2. **管好 feeToSetter 的钱包**：它唯一的权限是改「平台费收到哪」和「把这个权限交给谁」，碰不到任何人的池子。建议以后转给硬件钱包（见 `docs/安全/YubiKey入门.md`）。

## 8. 出事了怎么办（都不会丢钱）

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 钱包弹窗估 Gas 失败 | 构造参数填错（比如 `_feeToSetter` 留空） | 取消，重填 |
| ④ hash 不一致 | 编译设置和 BSC 不同 | 回第 2 步，重部署 ②③（①不用重来） |
| 加流动性失败 `EXPIRED` | 钱包确认太慢，超过 20 分钟有效期 | 再点一次 |
| 加流动性失败 `INSUFFICIENT_A_AMOUNT` | 两个币比例和池子现价差太多 | 页面会自动按池子比例补，刷新再试 |
| 兑换失败 `INSUFFICIENT_OUTPUT_AMOUNT` | 价格变了超过滑点 | 页面上把滑点调大一点点，或者再试 |

合约失败的交易只扣 Gas，币不会动。
